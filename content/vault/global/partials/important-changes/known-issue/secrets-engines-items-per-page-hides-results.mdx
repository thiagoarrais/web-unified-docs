#### Issue

On the **Secrets Engines** page in the Vault UI, changing **Items per page**
from a later results page can leave the table empty even when the item count
still indicates results are available.

This can happen when users start on page 2 or later with a smaller page size,
such as `5`, and then increase the page size to `25`, `50`, or `100`. The issue
is limited to the UI list view and does not affect the underlying mounts.

#### Workaround

Return to page 1 before increasing **Items per page**.

If the table still appears empty after changing the page size, refresh the page
and retry the action from the first results page.
